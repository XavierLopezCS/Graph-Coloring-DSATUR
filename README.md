# Graph-Coloring-DSATUR

# Graph Coloring Solver — DSATUR Algorithm (C++)

This program implements the DSATUR (Degree of Saturation) heuristic to color the vertices of a graph while minimizing the total number of colors used. The algorithm selects the next vertex to color based on its saturation degree (number of differently colored adjacent vertices), providing an efficient approach to graph coloring.

## Features
- Parses graph structure from an external text file into an adjacency matrix.
- Computes vertex degree and saturation dynamically.
- Selects the next vertex using DSATUR heuristic.
- Ensures no two adjacent vertices share the same color.
- Outputs the final color assignment and total colors used.
